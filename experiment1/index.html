Git and GitHub

Web Designing Lab — Experiment 1

Aim

To understand version control using Git and GitHub, create branches, commit changes, merge branches, and publish project files online.

Introduction

Git is a version control system used to track changes in files. GitHub is an online platform used to store and share Git repositories.

Commands Used

  • git init — initializes a repository.
  • git add . — stages file changes.
  • git commit -m "message" — saves changes.
  • git checkout -b experiment1-branch — creates a new branch.
  • git push -u origin experiment1-branch — uploads the branch.
  • git checkout main — switches to the main branch.
  • git merge experiment1-branch — merges branch changes.
  • git push origin main — uploads the updated main branch.

Result

The repository was created and uploaded to GitHub. Changes were committed on a separate branch and successfully merged into the main branch.
